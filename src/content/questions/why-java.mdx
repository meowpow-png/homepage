---
prompt: Why exactly Java?
---

Because I believe production software should be built like a tank.

Deploying software to production is a bit like going to war. You wouldn’t ride a bicycle into a
war zone. If I see someone storming a battlefield on a Vespa, I reserve the right to ask
questions.

Of course, you also wouldn’t use a tank to deliver a pizza. That’s where Go comes in.

I also keep Python installed as a reminder that nobody’s perfect.
