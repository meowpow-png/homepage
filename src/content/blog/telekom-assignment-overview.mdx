When Hrvatski Telekom posted a take-home assignment, the task seemed quite straightforward:

> Build a REST wrapper around an existing SOAP platform.

Two endpoints:

- `GET` Wi-Fi configuration
- `PUT` Wi-Fi configuration

Receive REST, call SOAP, return REST.

They even provided the WSDL, an OpenAPI specification, and a Mockoon server, so I wouldn't
have to think about the SOAP implementation itself. There were also a few optional bonus
tasks—local caching, synchronization, production readiness, maybe even a React frontend.

Two weeks later, those two endpoints had grown into a small platform: hexagonal
Spring Boot application with Postgres cache, JWT auth, password encryption, Grafana
dashboards, and a prototype for running isolated, containerized CLI agents.

This series tells the story of how that happened.
